## 1. Problem Statement

Given an integer array `nums`, return the minimum number of moves required to make all array elements equal.

In one move, you can increment or decrement any single element by 1.

### Example 1

**Input:**
```text
nums = [1, 2, 3]
```

**Output:**
```text
2
```

**Explanation:**
```text
[1, 2, 3]
[2, 2, 3]
[2, 2, 2]
```

### Example 2

**Input:**
```text
nums = [1, 10, 2, 9]
```

**Output:**
```text
16
```

---

## 2. Approach: Sorting + Median

### Key Observation

**To minimise the total number of increment/decrement operations required to make all elements equal, choose the median as the target.**

Unlike LeetCode 453, here we can increment or decrement any individual element.

Therefore, we need to minimise the sum of absolute differences.

### Example

```text
nums = [1, 10, 2, 9]
```

Sort the array:

```text
[1, 2, 9, 10]
```

The two middle elements are 2 and 9.

For an even-sized array, any value between the two middle elements gives the same minimum cost.

We can choose either 2 or 9.

Choosing 9:

```text
|1 - 9| = 8
|2 - 9| = 7
|9 - 9| = 0
|10 - 9| = 1

Total = 16
```

---

## 3. Why Does the Median Work?

We want to minimise:

\[
f(x)=\sum_{i=1}^{n}|nums[i]-x|
\]

Where `x` is the target value.

Consider the sorted array:

```text
[1, 2, 3, 4, 5]
```

The median is 3.

If we move the target one unit to the right:

- Elements on the left become one unit farther away.
- Elements on the right become one unit closer.

When the target is at the median, these two groups are balanced.

Moving away from the median cannot reduce the total cost.

Therefore, the median minimises the sum of absolute differences.

**Important mathematical property:**

\[
\boxed{\text{Minimise sum of absolute differences} \Rightarrow \text{Choose median}}
\]

For an even-sized array, every target between the two middle elements is optimal.

## 4. Java Solution (Primary)

### Optimal Approach

1. Sort the array.
2. Find the median.
3. Calculate the sum of absolute differences.

```java
import java.util.Arrays;

class Solution {
    public int minMoves2(int[] nums) {

        // Sort the array
        Arrays.sort(nums);

        // Find the median
        int median = nums[nums.length / 2];

        // Calculate the total moves
        long moves = 0;

        for (int num : nums) {
            moves += Math.abs((long) num - median);
        }

        return (int) moves;
    }
}
```

### Code Explanation

**Step 1: Sort the array**

```java
Arrays.sort(nums);
```

Sorting makes it easy to locate the middle element.

**Step 2: Find the median**

```java
int median = nums[nums.length / 2];
```

- Odd length: Select the middle element.
- Even length: Select either middle element. Both give the same minimum cost.

**Step 3: Calculate the total moves**

```java
long moves = 0;

for (int num : nums) {
    moves += Math.abs((long) num - median);
}
```

Calculate the absolute difference between each element and the median.

The sum represents the total operations required.

`long` is used for intermediate calculations to avoid integer overflow.

**Step 4: Return the result**

```java
return (int) moves;
```

The problem guarantees that the final answer fits in a 32-bit integer.

## 5. Python Solution (Secondary)

```python
class Solution:
    def minMoves2(self, nums: List[int]) -> int:

        # Sort the array
        nums.sort()

        # Find the median
        median = nums[len(nums) // 2]

        # Calculate total moves
        moves = 0

        for num in nums:
            moves += abs(num - median)

        return moves
```

### Alternative Python Implementation

```python
class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        nums.sort()
        median = nums[len(nums) // 2]

        return sum(abs(num - median) for num in nums)
```

## 7. Complexity Analysis

Let `n` be the number of elements.

| Operation | Time Complexity |
|---|---|
| Sorting | O(n log n) |
| Finding median | O(1) |
| Calculating differences | O(n) |
| Overall | O(n log n) |

**Space Complexity:**

- Java: O(log n) implementation-dependent sorting stack space for primitive array sorting.
- Python: O(n) auxiliary memory in the worst case for sorting.

## 8. Mathematical Optimisation Patterns

Remember these important relationships:

| Objective | Optimal Choice |
|---|---|
| Minimise sum of absolute differences | Median |
| Minimise sum of squared differences | Mean |
| Minimise decrements in LeetCode 453's equivalent operation | Minimum element |

The key is identifying the mathematical objective before selecting an algorithm.

## 10. Common Mistakes and Edge Cases

| Scenario | Expected Result |
|---|---|
| Single-element array | 0 |
| Already equal elements | 0 |
| Two elements | Absolute difference |
| Even-sized array | Either middle element works |
| Negative values | Median approach still works |

Common mistakes:

1. Choosing the mean instead of the median.
2. Forgetting to sort the array.
3. Not using absolute differences.
4. Assuming an even-sized array has only one optimal target.
5. Ignoring potential integer overflow in intermediate calculations.
